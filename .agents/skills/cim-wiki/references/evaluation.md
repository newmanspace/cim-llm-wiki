# 7 维质量评分规范（Stage 3）

> 迁移自 `internal/pipeline/evaluator/evaluator.go`。权重为 POC 初始值，后续须用 Golden Dataset 校准。

## 总分公式

```
Total = w_auth·S_auth + w_comp·S_comp + w_rel·S_rel + w_fresh·S_fresh
      + w_struct·S_struct + w_reuse·S_reuse + w_risk·(1 − S_risk)
```

| 维度 | 权重 | 含义 |
|------|------|------|
| S_auth | 0.20 | 来源可信度 |
| S_comp | 0.20 | 内容完整性 |
| S_rel | 0.15 | 产品相关性 |
| S_fresh | 0.15 | 时效性 |
| S_struct | 0.10 | 结构质量 |
| S_reuse | 0.10 | 可复用性 |
| S_risk | 0.10 | 冲突风险（**反向计分**，贡献 = w·(1−S_risk)） |

结果截断到 [0,1]，保留 4 位小数。

## 各维度打分细则

### S_auth 来源可信度（按源文件类型）
- `.pdf / .docx / .pptx / .doc / .ppt / .xlsx`（正式设计文档）→ 1.0
- `.md / .txt` → 0.75
- 来源含 git/commit → 0.65
- 无来源 → 0.30；其他 → 0.50

### S_comp 完整性
必填字段：`id, type, title, content, domain, version, source`。每缺一项 −0.15，下限 0。

### S_rel 产品相关性
基础 0.5；有 module +0.20；有 version +0.15；有 domain +0.15；上限 1.0。
相关性依据绑定项目的业务范围及来源证据判断，不因命中某类业务词直接加分。

### S_fresh 时效性（按文档更新时间距今）
≤90 天 → 1.0；≤365 天 → 0.80；≤730 天 → 0.60；更久或未知 → 0.40。

### S_struct 结构质量
基础 0.4；含 1~3 级标题 +0.20；正文 >100 字符 +0.15；含代码块 +0.15；含 Markdown 表格 +0.10；上限 1.0。

### S_reuse 可复用性（按 related_* 关联总数）
≥4 → 1.0；3 → 0.85；2 → 0.70；1 → 0.55；0 → 0.40。

### S_risk 冲突风险
结合实际影响、来源矛盾、信息缺失及既有节点冲突评估风险，附具体证据和原因。风险分数越高表示风险越大；不能仅按业务词出现次数推导分值或审核等级。来源不足时明确不确定性，不编造低风险结论。

## 冲突检测

同批次内 ID 相同但 content 不同 → 两个节点互相标记 `conflict_with`，并计入 S_risk。
与 `data/wiki/` 既有页面同 ID 但内容实质不同 → 同样标记冲突，审核卡片中必须高亮为「高风险（冲突）」，由用户裁决保留旧版或覆盖。

## 审核等级门限

| Total | review_level | 处置 |
|-------|--------------|------|
| ≥ 0.95 | L0_auto | 仅具备申请自动放行的评分条件；仍受服务配置和审核门禁约束 |
| ≥ 0.80 | L1_expert | 进入聚合审核卡片，领域专家确认 |
| ≥ 0.55 | L2_arch | 进入聚合审核卡片并标注需架构师裁决 |
| < 0.55 | archive | 归档到 data/review/archived/，不入主库 |

以上为当前服务的评分等级门限，服务可能要求更严格的审核；以实际校验和返回状态为准。完整策略未通过 `context` 暴露，不能声称已读取项目级审核配置。服务端现有关键词升级规则的限制见[服务调用契约](service-api.md#受控枚举与机器契约)。Skill 不另行维护业务关键词清单。

达到 L0 不代表已经获准发布；默认需要独立人工审核，只有服务端明确开启自动发布并返回自动放行状态时才可进入自动流程。

## 服务端交接格式

语义评分由当前本地 Agent/LLM 执行。每个节点使用 `qscore: {auth, comp, rel, fresh, struct, reuse, risk, total}`，各维度为 [0,1] 数值；total 按上式保留四位小数。服务端只复算总分、检查门限及审核条件，不另行调用 LLM。source 应为登记后的共享稿件 URI；来源可信度依据来源记录的原始文件格式，不能因为转换稿扩展名为 .md 而降级正式 XLSX/PDF 原件。

已有页面变更需用户批准，即使分数达到 L0；审核等级遵循服务端实际要求。审批针对服务端保存的提交快照，修订用新的 Bundle ID。
