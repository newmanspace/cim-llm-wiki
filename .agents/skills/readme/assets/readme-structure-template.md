# README Structure Template

> `readme` 技能在生成 README 文档时参考此骨架结构。

## Standard Sections

```markdown
# Project Name

> One-liner: 这是个什么项目，解决什么痛点。

[![Version](https://img.shields.io/badge/version-X.Y.Z-blue)]()
[![License](https://img.shields.io/badge/license-MIT-green)]()

## Quick Start

最快跑起来的核心几行命令。

## Features

- ✅ Feature 1
- ✅ Feature 2

## Installation

详尽的环境配置与依赖安装步骤。

## Usage

具体的代码运行或核心业务说明。

## API Reference

向外暴露的工具簇与接口引用文档。

## Architecture

项目的技术架构与分层设计。

## Contributing

内部开发流程与提交指南。

## License

许可证信息。
```
