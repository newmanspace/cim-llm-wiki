## Blockers

当前设计无未解决的数据库阻断项。以下问题已在方案中设置必需约束，编码时不能降级成仅前端校验。

| 检查点 | 设计处置 | 实施验证 |
|---|---|---|
| 并发层级成环 | 统一事务层级锁、锁内重查祖先、限制类型与深度 | 两连接并发互设父级 |
| 跨空间基线引用 | 复合唯一键／外键与父级所属校验 | 注入其他空间和其他版本的基线 |
| NULL scope 唯一性 | common／version 部分唯一索引 | 公共页重复 key 与重复目录 |
| 继承路径冲突 | 锁版本行，验证完整合并树后递增 generation | 本地新增与父目录同 slug |
| 推荐版本错绑 | 独立偏好表、复合 FK、事务校验发布状态 | 跨空间及未发布版本绑定 |
| 迁移失败被忽略 | 迁移台账、逐文件事务、失败终止启动 | 失败重启与幂等重跑 |
| 双存储半发布 | outbox 与 ready 门禁、幂等回调 | 写对象后进程崩溃 |
| 历史数据误删除 | 基线不可变、引用对象禁止删除、归档替代级联删除 | 仍被引用附件及版本删除 |

## Warnings

| 位置 | 风险 | 处理要求 |
|---|---|---|
| 第 4.1 章实体字段 | 目前为字段级设计，尚无执行版 DDL | 编码阶段补齐类型、长度、外键延迟创建、触发器和迁移测试，不直接将表格当作已部署 schema |
| 第 4.3 章旧数据 | 当前旧主键和新 sys_id 不一致 | 保留 legacy_project_id 映射，不按规范批量重建旧表 |
| JSONB 清单与元数据 | 任意 JSON 可能破坏契约 | 使用版本化 schema 严格验证，索引关键查询字段而非整表 JSON 扫描 |
| 关系锁 | 全局层级写锁会串行化改树 | 小团队首期可接受，内容编辑不持有该锁；记录锁超时 |
| 标识容量 | SERIAL 存在容量上限 | 首期符合项目技能规范；容量超出前评估迁移，审计与任务使用 UUID |
